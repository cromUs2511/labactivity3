# Lab Activity 3 - Task Management System

CPE106L-4 Software Design Laboratory

This project is a Python-based Task Management System developed using Object-Oriented Programming.

The system uses two classes:

* Task
* TaskManager

Features:

1. Add Task
2. View All Tasks
3. Search Task
4. Update Task
5. Delete Task
6. Mark Task as Completed
7. Exit

The program demonstrates:

* Classes
* Objects
* Constructors
* Instance attributes
* Instance methods
* Object relationships
* Encapsulation

To run the program, open the project in Visual Studio Code, select the Python interpreter from the .venv environment, open task_management.py, and click **Run Python File**.

Test cases:

1. Add a task and view all tasks.
2. Search for an existing task.
3. Update an existing task.
4. Mark an existing task as completed.
5. Delete an existing task.
