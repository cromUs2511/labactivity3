Program Overview:
This Python program implements a simple Study Task Tracker using Object-Oriented Programming (OOP). It organizes and tracks study sessions for the given class courses.

Classes Implemented:

1. StudyItem - Represents an individual study task. Stores the course code, activity description, priority, and tracks whether the item is pending, in progress, or finished.
2. StudyTracker - Manages the list of study tasks. Handles adding tasks, removing tasks, viewing active tasks, and filtering completed tasks.


How to Run:

1. Open a terminal or command prompt in the project folder.
2. Run the program using:
python main.py

Program Execution Summary:

* Adds initial study tasks for different courses.
* Displays the active study list.
* Updates task states (sets in-progress and finished).
* Removes a dropped task from the list.
* Adds a new task during the session.
* Displays the updated list and shows all completed tasks.
